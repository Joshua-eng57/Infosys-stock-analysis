Infosys Stock Analysis using Python
📌 Project Overview

This project analyzes the historical stock price data of Infosys using Python.
It fetches real stock market data, performs basic financial analysis, calculates daily returns and moving averages, and visualizes price trends.

🛠️ Technologies Used

Python

yfinance

pandas

matplotlib

📊 Features

Fetches real stock data from Yahoo Finance

Analyzes last 5 months of price data

Calculates:

Highest and lowest price

Daily returns

20-day and 50-day moving averages

Visualizes stock price trends using line charts

Saves analyzed data to a CSV file

📂 Project Files

main.py – Python script for analysis

infosys_stock_analysis.csv – Saved stock data

README.md – Project description

▶ How to Run

Install required libraries:

pip install yfinance pandas matplotlib


Run the script:

python main.py
